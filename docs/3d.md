# 3D layer

The public site renders interactive 3D equipment in two CMS sections, **Hero** (`scene` prop) and
**3D equipment showcase** (`equipment3d`). Both are driven by `SceneConfig`
(`shared/src/scene.ts`): model id, transform, camera, environment preset, auto-rotate, interaction
and scroll animation. The scene is a progressive enhancement: the page is complete without it.

## Architecture (`client/src/3d/`)

| File | Role | Imports three? |
| --- | --- | --- |
| `SceneCanvas.tsx` | Public entry point. Detects WebGL, waits until the element is near the viewport, lazy-loads `SceneRoot`, pauses rendering when off-screen or when the tab is hidden, and cross-fades from the poster when the first frames are ready. Error boundary: any failure falls back to the poster. | **No** |
| `ScenePoster.tsx` | Theme-aware SVG composition (bumper plate / dumbbell). Used as the loading state and as the permanent fallback (no WebGL, data-saver, context lost). Uses the hero `imageUrl` instead when one is set. | No |
| `quality.ts` | `useQualityTier()`, `hasWebGL()`, `useViewport()`, `usePageVisible()`, `usePrefersReducedMotion()`. | No |
| `SceneRoot.tsx` | The R3F `<Canvas>`: camera sync, lighting, model stage, a baked floor shadow, post-processing, `PerformanceMonitor` (drops DPR under load), glTF progress UI. **Lazy chunk.** | Yes |
| `Lighting.tsx` | `<Environment frames={1}>` built from `<Lightformer>`s (overhead softbox, two tall strips for chrome highlights, warm and cool rims, low fill, faint accent ring). Presets: `studio`, `night`, `warm`. **No HDR files are downloaded.** | Yes |
| `Rig.tsx` | Motion: auto-rotate (`spin`) or `sway`, idle float, mouse parallax (clamped ±0.28/±0.12 rad), horizontal drag-to-rotate (`touch-action: pan-y` keeps vertical page scroll; the wheel is never captured, so there is no zoom hijacking), and a GSAP ScrollTrigger scrubbed rotation and drop tied to the hero's scroll progress. Cleans up on unmount. | Yes |
| `materials.tsx` | Shared PBR materials plus **generated canvas textures**: a diamond-knurl normal and roughness map (Sobel height→normal), an EPDM rubber fleck map with micro-normal, brushed-steel roughness, and label decals (`20 KG`, `22.5 KG`, tick ring) in the theme primary colour. The primary colour is read from the `--c-primary` CSS variable and follows live theme changes. Textures are 1024/512/256 px by tier and are disposed on unmount. | Yes |
| `models/*` | Procedural, real-scale (metres) models: `WeightPlate` (rounded lathe rubber body, brushed hub insert, label decal, accent ring), `Barbell` (2.2 m, knurl zones with IWF marks, chrome flanges, bronze bushings, ribbed sleeves, collars), `Dumbbell` (bevelled hex extrusions, knurled handle, chrome collars, end caps with label and screw), `Kettlebell` (spline-lathe cast body, swept-tube handle, horns, colour weight band), `Bench` (adjustable FID), `HeroStack` (still life). | Yes |
| `models/registry.tsx` | `MODEL_REGISTRY` maps ids to components, plus `size`, `motion` and resting angle. `<Fit>` auto-centres and scales any model (procedural or glTF) from its local bounding box. Also contains `resolveModel()`, glTF loading and the glTF error boundary. | Yes |

Code splitting (verified with `npx vite build`): `three` (≈177 KB gz), `r3f` (fiber + drei +
postprocessing, ≈128 KB gz), `gsap` and `SceneRoot` are separate chunks that are **not** preloaded
by `index.html`. They load only when a scene nears the viewport.

## Quality tiers (`useQualityTier`)

The tier is derived from `hardwareConcurrency`, `deviceMemory`, the short screen side, a coarse pointer, DPR,
`navigator.connection.saveData` and 2G connections.

| | low | medium | high |
| --- | --- | --- | --- |
| DPR cap | 1.25 | 1.5 | 2 (phones always ≤ 1.5) |
| Antialias | off | on | on (MSAA 4× in composer) |
| Shadow maps | off | off | on (soft) |
| Floor shadow | light | baked footprint | baked footprint |
| Environment cube | 64 | 128 | 256 |
| Texture size | 256 | 512 | 1024 |
| Surface detail (knurl normal maps, segments) | off / 0.6× | on / 0.85× | on / 1× |
| Post-processing | none | Bloom + SMAA | Bloom + MSAA |

* `frameloop` is `always` only while auto-rotating and on screen. It is `demand` when idle (pointer and scroll
  invalidate frames) and `never` when off-screen or when the tab is hidden.
* **Reduced motion**: no auto-rotate, float, parallax easing or scroll animation, and no post-processing.
  The model renders as a still and can still be dragged. The custom cursor is disabled too.
* **Save-Data**: the 3D chunk is never downloaded and the poster is shown.
* Budget: the hero composition is ≈62k triangles at the medium tier (≈75k at high), with 93 meshes.

## Fallbacks

1. No WebGL (or `saveData`): the poster is shown (or the hero image when set).
2. The chunk fails to load, a render throws, or the WebGL context is lost: the error boundary shows the poster.
3. A glTF fails to load or parse: the procedural dumbbell is shown instead.

## Adding a licensed `.glb`

**Option A: upload (recommended).** Admin → Website → 3D models. The server validates the file
type and size, and the model must be **approved** before it appears in `GET /cms/site` →
`models` as `{ id: 'asset:<mediaId>', kind: 'gltf', url }`. Editors can then pick it in any scene
field (`modelId: "asset:<id>"`). It renders through the same lighting, floor shadow and
post-processing pipeline, auto-fitted by `<Fit>`, with a loading progress bar (`useProgress`).

**Option B: bundle it.** Put the file in `client/public/models/<name>.glb` (served at
`/models/<name>.glb`), register it in `BUNDLED_GLTF` in `client/src/3d/models/registry.tsx`
(`{ url: '/models/<name>.glb', size: 2.6 }`), and add the id to `BUILTIN_MODELS` in `shared/src/scene.ts`.

File guidance: glTF 2.0 binary, PBR metallic-roughness, ≤ 3 MB, textures ≤ 2K, ideally
≤ 50k triangles. Use **uncompressed or meshopt** compression. Draco is intentionally disabled
so no decoder is fetched from a third-party CDN. Real-world scale is not required.

### Swapping in photogrammetry

External model libraries are not reachable from the build container. To use a scanned model:

1. Download it on your own machine from a source whose licence permits commercial web use, for example Poly Haven
   (CC0) or Sketchfab models marked CC-BY or CC0.
2. Optimise it with `gltf-transform optimize in.glb out.glb --compress meshopt --texture-compress webp`
   (keep it under 3 MB).
3. Upload it via Admin → Website → 3D models, then approve it.
4. Set the hero's or showcase item's model to the uploaded asset.

* All procedural geometry and generated textures in `client/src/3d` are original code and ship with
  the project. There are no third-party 3D assets or HDRIs.
* For uploaded or bundled models, keep the licence and attribution with the asset (for example in the media
